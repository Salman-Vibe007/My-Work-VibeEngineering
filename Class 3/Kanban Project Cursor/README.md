# Kanban Project

A single-board Kanban project management MVP.

## Prerequisites

- Node.js 20+
- npm

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Testing

```bash
cd frontend
npm test          # unit and component tests
npm run test:e2e  # Playwright E2E tests
```
